# ワールドカップ2026 せかい地図アプリ

小学生の自由研究で作った、**2026 FIFAワールドカップ**の学習アプリです。
世界地図から国をえらんで、その国のじょうほうと、ワールドカップ本大会の試合けっかを調べられます。

> このアプリは家族のサポートを受けながら、子どもの自由研究として作りました。
> 名前・学校名・住所・写真などの個人情報は、いっさいのせていません。

## このアプリでできること

- 🌍 世界地図を見る(拡大・縮小もできます)。ワールドカップ2026に出た**48か国が緑色**で表示されます
  - 地図に形がのっていない小さな島国(カーボベルデ・キュラソー)は、丸いしるしで表示します
  - イングランドとスコットランドは、地図では同じ「イギリス」の場所になるので、タップすると2チームぶんの情報が出ます
- 🚩 国をタップすると、**その国の試合がぜんぶリストにならびます**。国のじょうほうも見られます
  - 国旗・首都・人口・広さ(日本とのくらべっこ)・ことば・お金
- ⚽ リストから試合をえらぶと、くわしいけっかが出ます
  - スコア(ホームは左、アウェイは右)。延長戦・PK戦にも対応
  - 得点した選手と時間
  - 先発メンバーとフォーメーション(サッカーコートの上に表示)。交代で下がった選手には「(66分OUT)」、とちゅうから出た選手は「名前(66分IN・だれとこうたい)」の形でまとめて出ます
  - 地図の上で、たたかった2つの国が点線でつながり、まん中にスコアが出ます
- ⌨️ マウスだけでなく、キーボード(Tab・Enter)でも国をえらべます

## 使用した技術

フレームワークは使わず、初心者にも分かりやすい作りにしています。

| 技術 | 使いみち |
|---|---|
| HTML / CSS / JavaScript(Vanilla) | 画面ぜんたい |
| [D3.js](https://d3js.org/) (v7) | 世界地図を描く・ズーム |
| [topojson-client](https://github.com/topojson/topojson-client) | 地図データの変換 |
| [world-atlas](https://github.com/topojson/world-atlas) | 世界地図のデータ(TopoJSON) |
| [flag-icons](https://github.com/lipis/flag-icons)(MITライセンス) | 48か国の国旗SVG(`assets/flags/`に同梱) |
| JSONファイル | 国と試合のデータ |

- バックエンド・データベース・APIキーは使っていません
- ライブラリと地図データはぜんぶ `libs/` と `data/` に入れてあるので、**毎回外部のAPIにアクセスしません**
- すべて相対パスで書いてあるので、GitHub Pagesのサブディレクトリ(`https://ユーザー名.github.io/リポジトリ名/`)でもそのまま動きます

## パソコン上で確認する方法

JSONファイルを読みこむため、HTMLファイルをダブルクリックしてそのまま開くと動かないことがあります。
かんたんな「ローカルサーバー」をとおして開いてください。

**方法1: Python を使う(入っていれば一番かんたん)**

```bash
python -m http.server 8000
```

このコマンドをこのフォルダで実行して、ブラウザで `http://localhost:8000` を開きます。

**方法2: VS Code の「Live Server」拡張機能を使う**

1. VS Code でこのフォルダを開く
2. 拡張機能「Live Server」を入れる
3. `index.html` を右クリック →「Open with Live Server」

## GitHub Pagesで公開する方法

このアプリは静的ファイルだけでできているので、**mainブランチをそのまま公開する方法**が一番かんたんです。

1. GitHubで自分のリポジトリのページを開く
2. 上のメニューの **Settings**(設定)を開く
3. 左のメニューの **Pages** を開く
4. 「Build and deployment」の **Source** で「**Deploy from a branch**」をえらぶ
5. **Branch** で「**main**」と「**/ (root)**」をえらんで **Save** をおす
6. 少し待つと、ページの上のほうに公開URL(`https://ユーザー名.github.io/リポジトリ名/`)が出ます

## 国のデータの直し方・足し方

出場48か国はすべて `data/countries.json` に入っています。1つの国はこの形です。

```json
{
  "id": "BRA", "mapId": "076", "group": "C",
  "nameJa": "ブラジル", "nameKana": "ぶらじる", "nameEn": "Brazil", "flag": "assets/flags/br.svg",
  "capital": "ブラジリア", "populationMan": 21600, "populationYear": 2023, "areaKm2": 8516000,
  "language": "ポルトガル語", "currency": "レアル", "anchorLngLat": [-47.88, -15.79]
}
```

- `id` は3文字の国コード(ISO 3166-1 alpha-3)
- `mapId` は地図データの国番号(ISO 3166-1 numeric)。この2つがアプリの中の「対応表」になっています
  - 番号が2けたの国は、`"076"` のように0をつけて3けたにします
  - 地図データに形がない小さな国は `null` にすると、首都の場所に丸いしるしが出ます
- `populationMan` は人口を「万人」で書いた数(例: 21600 → 約2億1600万人)。画面に出すときに、プログラムが「約○億○万人」のことばに直します
- `areaKm2` は広さ(平方キロメートル)。「日本の約○倍」も、ここから自動で計算します
- `anchorLngLat` は首都の [経度, 緯度]。対戦ラインのはしっこに使います
- 国旗は `assets/flags/` にある flag-icons のSVGを使います(ファイル名は2文字の国コード)

## 試合を追加する方法

`data/matches.json` の `matches` の中に、試合を1つ書き足します。
書き方は、すでに入っているオランダ対日本の試合をお手本にしてください。

だいじなルール(自由研究のやくそく):

- **2026年ワールドカップ本大会の試合だけ**を入れる(親善試合は入れない)
- スコア・得点者・時間は、**FIFA公式サイトなどでかくにんできたものだけ**を書く
- わからないところは、うそを書かずに空(`""` や `[]`)のままにする(画面には「かくにん中」と出ます)
- 選手のならびが公式でかくにんできないときは `formationConfirmed` を `false` にする(画面に「おおよそのならびです」と出ます)
- アディショナルタイムの時間は `"45+2"` や `"90+5"` のように書けます

## データの出典を追加する方法

それぞれの試合の `sources` に、じょうほうのもとにしたページを足します。

```json
"sources": [
  {
    "name": "FIFA 公式 試合ページ(英語)",
    "url": "https://www.fifa.com/..."
  }
]
```

ここに書いたリンクは、試合詳細の「じょうほうのもとを見る」にならびます。

## データの正確さについて

- 2026年ワールドカップ**本大会**の試合だけをのせています(架空の試合・架空の得点者はありません)
- いま入っている試合は、グループFの6試合と、日本・オランダのラウンド32の2試合です
- 試合のスコア・得点時間・交代は、FIFA公式サイト・ESPNなど複数の情報源をくらべてかくにんしました
- まだかくにんできていないところ(一部の試合の先発・交代・会場など)は、うそのデータでうめず、画面に「かくにん中」と出しています
- フォーメーションの選手のならびは、情報源によって書き方がちがうことがあるため、公式でかくにんできない部分は「おおよそのならび」と画面に表示しています
- 人口などの国のデータは年によって変わるため「約」をつけ、基準の年をいっしょに書いています
